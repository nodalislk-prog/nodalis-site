Paste your GitHub access token once, then choose a username and password — from then on, you, and anyone you trust with the username and password, sign in with those, on any device. The token is sealed with your password (AES encryption); without the password it is unreadable, and it is never shown to whoever signs in.

To create a token: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Repository access: Only select repositories → nodalis-site. Permissions: Contents → Read and write. Copy the token and keep it like a password.
